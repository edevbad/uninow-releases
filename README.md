# UniNow — Releases

**UniNow** is an offline-first Android app for COMSATS University Islamabad (Attock Campus) students that shows what class is happening right now, what's up next, and where to find an empty room — all from a homescreen widget, without needing a live connection once it's synced.

This repo hosts official app releases only. Source code is maintained privately.

## Why UniNow

Opening the university portal just to check a room number is slow. UniNow puts that answer on your homescreen — one glance, no app to open, works offline after the first sync.

## Features

- 📱 **Live homescreen widget** — current class, instructor, and room at a glance
- 🔄 **Shows your next class automatically** when nothing's currently running
- 📡 **Fully offline** once synced — no internet needed day-to-day
- 🏫 **Empty Room Finder** — see which classrooms are free right now, campus-wide
- 🗓 **Full weekly timetable**, with support for cross-section and cross-department course registration
- ⚡ **One-time setup** — pick your department, semester, and section once

## Download

Grab the latest APK from the [Releases page](../../releases/latest).

### Installation
1. Download the `.apk` file from the latest release
2. Open it on your Android phone
3. If prompted, allow **"install from unknown sources"** for this file — normal for apps installed outside the Play Store
4. Open the app and complete the one-time section setup
5. Long-press your homescreen → Widgets → find **UniNow** → add it

## Status

Currently scoped to **COMSATS Attock Campus**. Android only for now — iOS support is planned.
